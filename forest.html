我做了什么

  • 把「孩子在公园里没有探索目标」这一模糊问题，拆成 7 个真实分区、6 个 IP 角色、3 个功能模块的清单。
  • 定义「打卡 → 集章 → 升级 → 晒海报」的激励链路：7 枚印章对应 4 级成长，8 枚徽章覆盖多维度行为。
  • 用 AI 生成 IP 概念图并落到界面角色上，统一「光合青 + 叶脉金」的视觉体系。
  • 借 Cursor 完成可运行 Demo，玩法与交互逻辑由自己把控。

体验闭环

  • 游园前 先认识森林首页看 7 大分区与 6 位森灵，知道今天要去哪、能盖什么章。
  • 游园中 到点打卡在对应分区盖下专属印章，写下一条自然观察日记。
  • 游园后 沉淀成成就等级、印章墙、徽章自动结算，一键生成成就海报分享给家长群。

小程序 → H5 的等价替换

  • WXML → div / span / img，列表用数据驱动渲染
  • rpx → cqw 容器单位，750rpx 恒等于屏宽，手机壳内与全屏等比一致
  • wx.setStorageSync → localStorage，刷新不丢数据
  • wx.chooseMedia → input[type=file]，选图后压缩再入库
  • wx.canvasToTempFilePath → canvas.toDataURL + 浏览器下载
  • wx.openLocation → 站内分区导览图：以毕业设计的功能分区平面图为底图，SVG 叠加分区标记与行进路线

演示从零开始：先打卡集章、再写日记。想看完成态，可在「我的」页一键载入示例数据。
